The point of this code is to keep track of the uploaded finances of a discord server.
It automatically updates the topic to the current score of the total months fincances and the highest score reached.

Commands:

$add -> Needs to be accompanied by a number and it ads to your total spending
Format example: $add 20

$refund -> Needs to be accomanied by the transaction ID and be either from the user who made the transactino or from the user ID put as ADMIN_KEY
Format example: $refund 14

$check -> If input without the user you are checking it will display the servers month current total and the current grand total since being added
If it is input with a user it will display that users personal month spending and grand total
Format examples:
$check
$check @ChallengerLily

To use the bot you have to input the token where it belongs and the channel ID where you want it to work

It is pretty buggy and still being fully worked on!!
